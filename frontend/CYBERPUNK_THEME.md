# 🌃 Cyberpunk Theme Transformation

## 🎨 Design Philosophy

Transformed from futuristic sci-fi to **realistic cyberpunk** aesthetic:
- Darker, grittier color palette
- Authentic hacker/terminal vibes
- Realistic data visualization
- Authentic cyber styling

## 🎯 Color Palette

### Primary Colors
- **Cyber Cyan**: `#00ffc8` - Main accent (bright, neon)
- **Cyber Pink**: `#ff00ff` - Secondary accent (magenta)
- **Cyber Green**: `#00ff88` - Success/positive
- **Cyber Red**: `#ff3366` - Danger/negative
- **Cyber Blue**: `#0080ff` - Information

### Background Colors
- **Cyber Dark**: `#0d0221` - Main background (very dark purple)
- **Cyber Darker**: `#1a0033` - Darker purple for depth

## ✨ Visual Effects

### 1. **Scanlines**
- Animated horizontal lines across the entire screen
- 8-second animation cycle
- Creates authentic CRT monitor effect
- Opacity: 3%

### 2. **Cyberpunk Glow**
- Text shadow effects on headings
- Cyan and pink neon glows
- Realistic neon sign appearance

### 3. **Cyber Borders**
- Thin 1px borders with cyan/pink colors
- Inset glow effects
- Outer glow shadows

### 4. **Cyber Pulse**
- Pulsing box-shadow animation
- 2-second cycle
- Realistic "alive" indicator effect

### 5. **Glitch Effect**
- Chromatic aberration style text shadow
- Magenta and cyan color shifts
- 0.3s animation for quick glitch

### 6. **Cyber Scan**
- Animated scan line moving across cards
- 3-second animation
- Creates "data flowing" effect

## 🎭 Component Styling

### Cards
- Dark gradient backgrounds (purple to darker purple)
- Thin cyan borders
- Backdrop blur effect
- Scan line animation overlay
- Hover border glow

### Headers
- Uppercase text with wide letter spacing
- Neon glow on titles
- Monospace font for data
- Minimal, clean design

### Data Display
- Monospace font (IBM Plex Mono)
- Wide letter spacing (0.05em)
- Bold font weight (600)
- Cyan/green/pink colors

### Buttons & Controls
- Thin borders (1px)
- Minimal padding
- Square corners (rounded-sm)
- Hover state with border glow

## 🎬 Animations

### Entrance Animations
- `slide-up`: 0.6s ease-out
- `slide-down`: 0.6s ease-out
- `fade-in`: 0.6s ease-out

### Continuous Animations
- `cyber-pulse`: 2s ease-in-out infinite
- `cyber-scan`: 3s infinite
- `scanlines`: 8s linear infinite
- `glitch`: 0.3s infinite
